# BorderMe

BorderMe is a Finder Quick Action that creates new JPEG copies with a true white border outside the original image. The original files are never changed.

## Use

1. Select one or more images in Finder.
2. Right-click and choose **Quick Actions > BorderMe**.
3. Choose **Small**, **Medium**, or **Large** border thickness.
4. Choose a standard output size or an Instagram preset.

The bordered images are saved beside the originals. Existing files are never overwritten.

## Presets

- Border: Small 2%, Medium 5%, Large 8%.
- Standard output: Small 1200 px, Medium 2400 px, or Large original resolution.
- Instagram Portrait: 1080 x 1440 (3:4).
- Instagram Landscape: 1080 x 566 (1.91:1).

Instagram outputs place the complete uncropped image in the centre of an exact white canvas. The side and top borders may differ to accommodate the original aspect ratio.

If BorderMe is not visible in Finder, open **Quick Actions > Customize** and enable it.
